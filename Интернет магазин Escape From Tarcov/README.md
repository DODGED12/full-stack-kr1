## О проекте

Сайт-витрина с каталогом из шести услуг: покупка игровых рублей, получение Kappa,
сопровождение по квестам, сборки оружия, тренер PvP, издания игры.
Посетитель может изучить каталог, открыть страницу товара и оставить заявку.

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная: hero-блок с фоновым видео, преимущества, популярные услуги |
| `catalog.html` | Каталог: панель фильтров и карточки услуг |
| `product.html` | Описание всех товаров с особенностями каждого |
| `order.html` | Форма заявки с проверкой полей и окном подтверждения |
| `contacts.html` | Контакты, время работы, переход к заявке |

## Использованные технологии

- HTML5 и семантическая разметка (`header`, `nav`, `main`, `section`, `footer`)
- CSS3: переменные в `:root`, flexbox, grid, `position`, псевдоэлементы, `:hover`, `:focus-visible`, `:target`
- Адаптивная вёрстка: медиазапрос `@media (max-width: 767px)`, сетки `auto-fit` и `auto-fill`, перенос элементов (`flex-wrap`)
- Именование классов по методологии БЭМ (`block__element--modifier`)
- Шрифт Oswald (Google Fonts) для заголовков и кнопок

Фреймворки и библиотеки (в том числе Bootstrap) не использовались, все стили написаны вручную.

## Особенности реализации

- **Цветовая схема:** тёмная палитра «олива + янтарный акцент», все цвета и отступы заданы переменными в `:root`.
- **Видео в hero-блоке:** автозапуск без звука (`autoplay muted loop playsinline`), затемнение через псевдоэлемент `::before`.
- **Форма заявки:** поля имени, телефона, email, выбор услуги, комментарий, способ связи, согласие на обработку данных; проверка средствами HTML (`required`, `minlength`, `pattern`, `type="email"`).
- **Модальное окно:** подтверждение отправки заявки сделано без JavaScript, через якорь `#success` и CSS-селектор `:target`.
- **Адаптивность:** шапка на телефоне перестраивается в компактную строку, каталог и страница товара переходят на одну колонку.

## Запуск

Сборка не нужна. Достаточно открыть `index.html` в браузере или запустить проект
через расширение Five Server в VS Code.
