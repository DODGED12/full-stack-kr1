# TapTok

Учебный HTML/CSS-проект небольшого каталога механических клавиатур.

## Структура
- `index.html` — главная страница (hero, преимущества, популярные товары, связь);
- `catalog.html` — каталог (категории, фильтры, карточки товаров);
- `product.html` — карточка товара (характеристики, модальное окно);
- `order.html` — форма заявки;
- `contacts.html` — контакты и форма обратной связи;
- `css/style.css` — общие стили;
- `js/main.js` — минимальная работа модального окна;
- `images/` — изображения проекта.

## Технологии
HTML5, CSS3 (переменные, Flexbox, Grid, БЭМ), минимальный JavaScript.

Для просмотра откройте ссылку выше или файл `index.html` в браузере.
